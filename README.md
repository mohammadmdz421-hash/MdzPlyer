# MdzPlayer

**MdzPlayer** is an Android media-player project built with Kotlin/Java. The project is intended to provide a convenient place to browse and play video and audio, with support for subtitles and media-library features.

> **Project status:** Under active development. Features and setup details may change as the project evolves.

## Project areas

The codebase is organized around these main areas:

- **Formats** — media-format handling and playback support.
- **Subtitles** — subtitle-related functionality.
- **Library** — media-library features.
- **Network** — network-related media functionality.

## Goals

MdzPlayer aims to provide:

- Video playback with useful playback controls.
- Audio and music playback.
- Subtitle controls and support.
- A media library for accessing content.
- A responsive experience across a range of Android devices, including lower-powered phones and Android projectors.

The exact capabilities available depend on the current source code and build.

## Getting started

1. Install **Android Studio**.
2. Clone or download this repository.
3. Open the project in Android Studio.
4. Allow Gradle to sync and download the required dependencies.
5. Select an available Android device or emulator.
6. Build and run the app.

If the project does not sync, check that your Android Studio, Android Gradle Plugin, Gradle, and JDK versions are compatible with the versions declared by the project.
